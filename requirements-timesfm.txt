# Optional dependencies for the real Google TimesFM 2.5 (200M) forecasting engine.
# Not required for the base install — TimeInvestor runs fully on DampedHoltForecastEngine
# without any of this. Only install these if you plan to set USE_REAL_TIMESFM=true.
#
# Install with:
#   pip install -r requirements.txt -r requirements-timesfm.txt
#
# For a CPU-only machine (no NVIDIA GPU), install torch from the CPU wheel index first
# to avoid pulling unnecessary CUDA packages:
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements-timesfm.txt
#
# NOTE on version: the `timesfm` package on PyPI only ships TimesFM 2.5+ under the
# `timesfm.TimesFM_2p5_200M_torch` PyTorch class (checkpoint: google/timesfm-2.5-200m-pytorch).
# `timesfm==1.0.0` is JAX-only (requires jax/paxml/praxis) and is NOT what this project uses,
# despite the checkpoint naming convention from the original TimesFM 1.0 paper.
#
# PINNED to an exact version (verified 2026-09-25). Since 3.0.0 the package also
# ships TimesFM 3 (TimesFM3Torch), so a loose range lets `pip install -U` pull a
# release that might drop or change TimesFM_2p5_200M_torch. How 3.0.2 was
# verified, not assumed:
#   - installed version (`pip show timesfm`): 3.0.2, the latest on PyPI that day
#     (`pip index versions timesfm`: 3.0.2, 3.0.1, 3.0.0, 2.0.2, 2.0.1, 2.0.0, 1.0.0);
#   - `hasattr(timesfm, "TimesFM_2p5_200M_torch")` is True with it installed;
#   - the PyPI wheel itself (`pip download timesfm==3.0.2 --no-deps`) exports
#     that class in timesfm/__init__.py;
#   - the real-weights tests pass with it (test_timesfm_real_loads_when_weights_present,
#     test_selector_uses_timesfm_for_seasonal_fred_series).
# Before bumping: repeat those checks against the new version.
